# Workspace Instructions

## Architecture Skill

When designing, implementing, modifying, or refactoring fenestrator domain logic, reactive state, feature stores, runtime orchestration, Angular signals, persistence boundaries, or application architecture, use the `dsfr-architecture` skill.

Apply the skill especially for:

- Angular signal stores and derived state
- Domain ownership decisions
- Pure transforms versus orchestration
- Effect and IO boundaries
- Runtime request/response handling
- Git-backed project persistence flows
- Translation project/profile/memory state transitions

Keep async work at system boundaries and route resolved outcomes back through explicit domain entry points.
